## Non-negotiable invariants
1. Preserve existing Cashew data and features.
2. Offline-first; network failure must not corrupt financial state.
3. Financial writes must be atomic/idempotent where applicable.
4. Never silently invent exchange rates.
5. Arabic/English and RTL must remain supported.
6. AI/automation must not perform destructive/financial writes without explicit confirmation.
7. Do not mark a feature DONE merely because a database table or stub exists.

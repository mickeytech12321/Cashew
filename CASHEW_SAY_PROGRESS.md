## Phase 05 — Wealth
- PARTIAL: Settings → Assets and liabilities supports local entry creation, editing, deletion, quantity × unit value and a net recorded value per currency. A separate local investment ledger records buys, sales, fees, weighted-average cost basis, gains or losses, and dated manual quotes and price history. The investment detail screen offers a FIFO view alongside the default weighted-average calculation. Both use the existing chronological trade history, including fees and partial sales. The holding screen previews and imports up to 365 dated quotes from pasted CSV offline, skipping existing timestamps and updating current valuations only when a newer quote is added. Price history is paginated and includes confirmed removal. Deleting the current quote restores the latest remaining quote atomically, or clears the valuation when there are no quotes. Flutter verification and automatic provider prices remain. Consolidated wealth valuation and snapshots can include open investments as an opt-in; missing prices or exchange rates block a consolidated total.

## Non-negotiable invariants
1. Preserve existing Cashew data and features.
2. Offline-first; network failure must not corrupt financial state.
3. Financial writes must be atomic/idempotent where applicable.
4. Never silently invent exchange rates.
5. Arabic/English and RTL must remain supported.
6. AI/automation must not perform destructive/financial writes without explicit confirmation.
7. Do not mark a feature DONE merely because a database table or stub exists.
